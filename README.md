# Furniture-Website
A three-page furniture website built with HTML and CSS. It presents a range of furniture pieces in a clean, easy-to-browse layout, and lets visitors explore product options before getting in touch.

## Pages
- **Home**: introduction to the brand and featured furniture
- **Products / Customize**: browse items and view customization options
- **Contact**: ways to reach the business with enquiries or orders

## Built with
- HTML5
- CSS3

## Running it locally
Download or clone the repository and open `index.html` in any web browser. No installation or build step is needed.
